# DOCFLOW

> AI-powered document assistant using RAG and workflow automation.

## 📌 Overview

DOCFLOW is a Full-Stack AI application designed to help users interact with their documents through a simple conversational interface.

The project allows users to upload documents and ask questions about their content. DOCFLOW combines a modern web application with AI-powered document retrieval and workflow automation to provide contextual and useful answers.

The project is being developed as an MVP to explore Full-Stack development, REST API architecture, RAG systems, and workflow automation.

---

## ✨ What Can DOCFLOW Do?

DOCFLOW is designed to:

- Upload and manage documents.
- Allow users to ask questions about their documents.
- Use RAG to retrieve relevant information from uploaded documents.
- Generate contextual answers using AI.
- Use n8n to automate and connect different parts of the application.
- Provide a simple and modern interface for interacting with documents.

> More features will be added progressively as the project evolves.
